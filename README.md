# Feedomatic

This is a minimal RSS, Atom, and JSON Feed reader, now with Bubbatronic™ feed integration.

The fetcher supports JSON Feed 1.0 and 1.1 URLs, including feeds with a `.json` or `.feed` extension. JSON Feed entries use their `id`, `title`, `url`, `content_html` or `content_text`, and publication date fields.

Connect your GitHub repo to get started. Favorites, archived items, and deletions are stored locally on each device. GitHub is used to manage feeds and publish feed data. When you add a new feed, it will appear after a few minutes. Any new fetches happen at midnight. (You can change the time in the YAML file.)

Fonts are Geist and Geist Mono.
